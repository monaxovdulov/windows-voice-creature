# План проекта

## Цель

Создать Windows desktop-pet приложение: существо отображается поверх рабочего стола, само перемещается и выполняет простые голосовые команды пользователя.

## MVP

1. Прозрачное always-on-top окно без рамки.
2. Анимированное существо, нарисованное средствами Qt.
3. Автономное перемещение по экрану.
4. Push-to-talk режим через `Ctrl+Alt+Space`.
5. Офлайн-распознавание коротких русских команд.
6. Команды движения и остановки.
7. Документация и Windows-сборка через PyInstaller.

## Этапы

### Этап 1. Каркас приложения

- Создать Python-пакет.
- Настроить зависимости: PySide6, pynput, sounddevice, vosk.
- Добавить запуск через `python -m screen_creature`.

### Этап 2. Overlay

- Создать прозрачное окно поверх всех окон.
- Убрать рамку и кнопку в панели задач.
- Добавить рисованное существо.
- Ограничить движение границами текущего экрана.

### Этап 3. Поведение существа

- Добавить состояния `idle`, `walking`, `listening`, `dance`.
- Реализовать самостоятельные случайные решения: стоять, идти влево, идти вправо.
- Добавить реакции на команды.

### Этап 4. Голос

- Глобально слушать удержание горячей клавиши.
- Записывать микрофон только во время удержания.
- Распознавать фразу после отпускания клавиши.
- Ограничить словарь команд, чтобы повысить точность.

### Этап 5. Упаковка

- Добавить PyInstaller spec.
- Добавить Windows workflow в GitHub Actions.
- Описать ручную и автоматическую сборку.

## Следующие улучшения

- Настройки в трее: hotkey, скорость, микрофон, автозапуск.
- Несколько персонажей и скинов.
- Настоящие sprite-sheet анимации вместо QPainter.
- Поддержка нескольких мониторов.
- Локальное хранение настроек в `%APPDATA%`.
- Команды через Whisper или OpenAI API как дополнительный режим.

## Риски

- Глобальные hotkeys могут не работать в некоторых играх или приложениях, запущенных от администратора.
- Vosk-модель увеличивает размер релиза.
- Распознавание коротких русских слов зависит от микрофона и шума.
- Click-through режим удобен для работы, но отключает взаимодействие мышью с самим существом.
