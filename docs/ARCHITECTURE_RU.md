# Архитектура

## Модули

```text
src/screen_creature/
  app.py                  # точка входа QApplication
  config.py               # настройки из окружения
  overlay.py              # прозрачное окно, отрисовка, движение
  voice/
    commands.py           # словарь и парсер голосовых команд
    controller.py         # связь hotkey, записи, распознавания и UI
    hotkey.py             # глобальная push-to-talk клавиша
    recorder.py           # запись микрофона через sounddevice
    recognizer.py         # Vosk offline STT
```

## Поток данных

1. Пользователь удерживает `Ctrl+Alt+Space`.
2. `PushToTalkHotkey` отправляет Qt-сигнал `pressed`.
3. `VoiceController` включает `AudioRecorder`.
4. Существо переходит в состояние `listening`.
5. Пользователь отпускает клавиши.
6. Запись останавливается.
7. `VoskSpeechRecognizer` в отдельном потоке распознает короткую фразу.
8. `parse_voice_command` превращает текст в команду.
9. `OverlayWindow` меняет состояние и скорость существа.

## Почему PySide6

PySide6 дает простой способ сделать прозрачное окно, таймеры, отрисовку через QPainter и безопасные сигналы между потоками. Для desktop overlay это проще, чем pygame, потому что Qt лучше работает с окнами ОС.

## Почему Vosk

Vosk работает офлайн и подходит для коротких команд. Для MVP это важно: микрофон не отправляет звук во внешние сервисы, а команда распознается локально.

## Настройки через окружение

| Переменная | Значение |
| --- | --- |
| `CREATURE_VOSK_MODEL` | путь к папке Vosk-модели |
| `CREATURE_SPEED` | базовая скорость существа |
| `CREATURE_SAMPLE_RATE` | частота записи, по умолчанию `16000` |
| `CREATURE_CLICK_THROUGH` | `1`, чтобы клики проходили сквозь окно |
