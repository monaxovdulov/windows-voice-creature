# Windows Voice Creature

Windows-приложение на Python: живое существо отображается поверх экрана, ходит или парит по рабочему столу, реагирует на голосовые команды, умеет говорить текстовыми пузырями, падать на умную подставку и менять скины с разным поведением.

## Что уже реализовано

- Прозрачное окно без рамки поверх остальных окон.
- Рисованное существо без внешних ассетов.
- Самостоятельное движение по нижней части экрана.
- Перетаскивание мышью: существо можно поднять вверх и отпустить, после чего оно падает вниз с эффектом удара.
- Текстовые реплики по клику: текст печатается по буквам, а рот двигается во время "разговора".
- Умная подставка справа: ее можно свернуть в тонкую линию, раскрыть обратно и посадить на нее существо.
- Быстрые действия на подставке: домой, вниз, танец, смена скина, суперспособность, пауза/ходить, выход.
- Скины с разным характером, выражением лица, анимацией движения и способностями.
- Push-to-talk горячая клавиша `Ctrl+Alt+Space`.
- Запись микрофона только во время удержания клавиши.
- Офлайн-распознавание русских команд через Vosk.
- Команды: `вперед`, `назад`, `влево`, `вправо`, `стой`, `ко мне`, `танцуй`.
- Контекстное меню по правому клику: пауза автономного движения и выход.
- GitHub Actions workflow для сборки Windows-артефакта.

## Установка на Windows в одну команду

Нужны Windows 10/11, установленный `uv` и микрофон. Python отдельно ставить не нужно: `uv` сам скачает подходящий интерпретатор и создаст окружение.

В PowerShell:

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -Command "& ([scriptblock]::Create((irm 'https://raw.githubusercontent.com/monaxovdulov/windows-voice-creature/main/scripts/install.ps1'))) -Start"
```

Команда скачает проект в `%LOCALAPPDATA%\WindowsVoiceCreature`, выполнит `uv sync`, создаст ярлык на рабочем столе и запустит существо.

Если сразу нужны голосовые команды, добавьте скачивание русской Vosk-модели:

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -Command "& ([scriptblock]::Create((irm 'https://raw.githubusercontent.com/monaxovdulov/windows-voice-creature/main/scripts/install.ps1'))) -WithVoiceModel -Start"
```

Модель `vosk-model-small-ru-0.22` скачивается в папку `models/`. Архив весит примерно 44 MB, после распаковки занимает больше места.

Повторный запуск после установки:

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File "$env:LOCALAPPDATA\WindowsVoiceCreature\scripts\start.ps1"
```

Полезные флаги установщика:

| Флаг | Что делает |
| --- | --- |
| `-WithVoiceModel` | Скачивает русскую Vosk-модель для офлайн-распознавания речи. |
| `-Start` | Запускает приложение после установки. |
| `-NoShortcut` | Не создает ярлык на рабочем столе. |
| `-Dev` | Ставит dev-зависимости: `pytest`, `ruff`, `pyinstaller`. |
| `-InstallDir "C:\Path\To\App"` | Устанавливает проект в указанную папку. |

## Быстрый запуск из клона репозитория

Нужны Windows 10/11, `uv` и микрофон.

```powershell
git clone https://github.com/monaxovdulov/windows-voice-creature.git
cd windows-voice-creature

uv sync
.\scripts\start.ps1
```

Для разработки:

```powershell
uv sync --extra dev
uv run pytest
```

Без Vosk-модели существо запустится, но голосовые команды будут выключены. Для включения речи скачайте русскую модель:

```powershell
.\scripts\download_vosk_model.ps1
.\scripts\start.ps1
```

Скрипт скачивает `vosk-model-small-ru-0.22` в папку `models/`.

## Управление

- Левый клик по существу показывает короткую реплику.
- Зажмите левую кнопку мыши на существе, перетащите его вверх и отпустите: оно упадет вниз.
- Если отпустить существо над раскрытой подставкой справа, оно приземлится на платформу и останется "на базе".
- Клик по свернутой тонкой линии подставки раскрывает ее обратно.
- Удерживайте `Ctrl+Alt+Space`, скажите команду и отпустите клавиши.
- Правый клик по существу открывает меню.
- Если нужно, чтобы окно пропускало клики насквозь:

```powershell
$env:CREATURE_CLICK_THROUGH = "1"
uv run python -m screen_creature
```

В этом режиме правый клик по существу уже не откроет меню, потому что клики будут проходить в окно под ним.

## Скины и способности

| Скин | Поведение | Суперспособность |
| --- | --- | --- |
| `Мятный` | Спокойно ходит вперевалку, любопытное выражение лица. | `Уют`: отправляется на подставку и переходит в спокойный режим. |
| `Ночной` | Парит над нижней частью экрана, мечтательное лицо и антенны. | `Портал`: переносится к курсору. |
| `Искра` | Двигается резкими прыжками, дерзкое лицо и след при рывке. | `Рывок`: быстро бросается в сторону курсора. |

Скин переключается кнопкой `Скин: ...` на подставке. Кнопка `Сила: ...` запускает способность текущего существа.

## Голосовые команды

| Фраза | Действие |
| --- | --- |
| `вперед`, `иди вперед` | идет в текущем направлении |
| `назад`, `иди назад` | идет обратно |
| `влево`, `налево` | идет влево |
| `вправо`, `направо` | идет вправо |
| `стой`, `стоп`, `остановись` | останавливается |
| `ко мне`, `подойди`, `сюда` | идет к позиции курсора по X |
| `танцуй`, `потанцуй` | короткая анимация |

## Сборка `.exe`

На Windows:

```powershell
uv sync --extra dev
uv run python scripts\build_windows.py
```

Результат будет в `dist/screen-creature/`. Если папка `models/` существует, PyInstaller добавит ее в сборку. Для публичного релиза лучше не включать модель в репозиторий, а прикладывать ее отдельным архивом или скачивать при установке.
